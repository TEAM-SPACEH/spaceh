# 기능 목록 (28개)

팀 드라이브의 「기능명세표」를 저장소에서 찾아보기 쉽게 옮긴 색인이다. 상세 설명·메소드 시그니처는 명세표와 메소드 명세서가 source of truth이고, 이 표와 다르면 명세표를 따른다. 일정은 WBS 기준이다 (Day 1 = 10/21, Day 4 = 10/26, Day 5 = 10/27 관문, Day 7 = 10/29 정오 기능 동결).
