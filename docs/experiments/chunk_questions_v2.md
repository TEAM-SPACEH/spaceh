# 청킹 테스트 질문 12개

문서당 3개씩 준비한 **기존 실행 점검·설정 선택용 질문**이다. 이 12개는 현재 색인에서 기준선 평가를 완료했다.
새 비교 실험은 [추가 22문항](chunk_questions_additional.json)을 합쳐 비교용 30개·추출 진단용 4개로 진행한다. [실행 방법](chunk_comparison_run.md)
일부 기존 문항·근거를 재사용했으므로 최종 검증에는 별도의 새 질문을 사용한다.

## 사용 방법

- **비교용 8개:** 추출된 근거가 확인된 질문. 청크 설정별 성공률을 비교한다.
- **오류 확인용 4개:** 표 누락·OCR 오인식이 있는 질문. 비교용 점수와 따로 집계한다.
- 정답은 원본 기준이다. 검색 결과에 맞춰 정답을 바꾸거나 없는 근거를 보충하지 않는다.
- 정답에 필요한 사실이 검색 결과에 모두 있으면 성공으로 판정한다. 표현 차이는 허용한다.
- PDF는 파일 첫 쪽부터 센 번호다. DOCX는 페이지가 아닌 문단·표를 합친 블록 순번이다.
- 추출 상태는 작성 시점 기준이며, 재색인하면 다시 확인한다.

## 오류 확인 문항의 현재 상태

| 번호 | 확인된 문제 |
|---|---|
| Q03 | 스마트솔루션팀 → 스마트슬루선팀으로 OCR 오인식 |
| Q06 | 원본 6200kg이 해당 쪽 저장 청크에서 누락 |
| Q08 | 엣지 처리 → 옛지 처리 등 OCR 오인식 |
| Q09 | 인증 → 인종으로 OCR 오인식 |

중동 보고서의 수치는 모의 문서의 가정이며, ARIA도 모의 기획안이다.
이 질문셋은 문서 근거를 찾는 성능을 평가하며 실제 투자 정보나 제품 성능을 검증하지 않는다.

자동 실행에 사용할 문서 ID·원본 해시·필수 정답 요소는 `chunk_questions_v2.json`에 저장했다.
