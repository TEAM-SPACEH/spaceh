# 청크 크기 1차 비교 결과

이 문서는 실험 실행 당시의 기록이다. 이후 #136에서 요청한 기본값 800/80 적용과 재색인 안내는 [자료 안내](README.md)를 따른다.

## 현재 선택 기준: 하이브리드

사용자가 아래 벡터 결과를 확인한 뒤 주 기준을 하이브리드로 변경했다. 결과를 보고 변경한 탐색적 분석이며, 사전 확정된 검증 결과로 표현하지 않는다.
비교용 30문항 × 5설정 × 2분량의 하이브리드 300개 조합을 에이전트가 검색 근거와 대조했다. 모호한 Q04는 동일하게 제외했다. 독립된 사람의 재채점은 아니다.

| 크기/오버랩 (글자) | 하이브리드 4,000토큰 | 하이브리드 Top 10 | 전체 임베딩 입력 토큰 |
| --- | ---: | ---: | ---: |
| BASE: 800/150 | 23/29 | 25/29 | 525,373 |
| 400/40 | **26/29** | **26/29** | 644,490 |
| 800/80 | **26/29** | **26/29** | 519,733 |
| 1200/120 | 23/29 | **26/29** | 496,002 |
| 1600/160 | 23/29 | 25/29 | 482,823 |

400/40과 800/80은 두 성공 수가 같다. 전체 임베딩 입력량이 약 19% 적은 **800/80을 2차 잠정 후보**로 선택했다. 검색 정확도가 더 높다는 뜻은 아니다.
주 지표에서 400만 성공한 것은 Q17·Q31, 800만 성공한 것은 Q12·Q25다. 800/80은 BASE 대비 Q02·Q12·Q24를 추가로 성공했고 BASE만 성공한 문항은 없다.

주요 대조 내용:

- Q18·Q20·Q21·Q22: 정답 표·본문은 있지만 인용의 조사·구분자·OCR 철자를 바꿔 보류한 사례를 통과로 정정했다.
- BASE의 4,000토큰 Q02: 사용자 교육·훈련이 검색되지 않았는데 일반 IT서비스에 포함된다고 추정해 통과시킨 것을 실패로 정정했다.
- 800/80의 Top 10 Q17: WCS 행만 있고 WMS 행은 없다. 모델이 WMS 인용을 만들어낸 보류 판정을 실패로 정정했다.
- Q13: 설치 위치 일부만 검색된 경우 냉난방 효율·열차풍·소음·분진 효과까지 충족하지 않으므로 실패다.
- Q23: 하이브리드는 모든 설정에서 p.10의 반원형 모델 설명과 인증·비용·납기 안내를 함께 검색했다. 같은 페이지의 서로 다른 청크도 함께 근거로 사용할 수 있으므로 통과다. 벡터에서 모델 문맥이 검색되지 않은 경우와 다르다.

정정은 별도 `agent_review_hybrid_size.json`으로 남기고 원본 자동 결과와 기존 벡터 검토 기록은 보존한다.
이후 800자에 오버랩 0·80·160자의 2차 비교를 완료했다. [2차 결과·재검색 변동](chunk_overlap_results_20261101.md). 앱 기본값은 변경하지 않았다.

## 근거와 대조한 중요한 사례

- **Q04 — 질문의 모호성:** 전망창 형태를 지정하지 않아 같은 LUXEN MR·1350kg에서도 여러 내부 규격이 가능하다. 모델은 정답의 1800×1600과 다른 1800×1800 행을 인용하고 통과시키기도 했다. BASE 확인 중 다른 크기의 결과를 보기 전에 제외 민감도 분석을 기록했다. 원래 30문항 자동 표는 보존하고 선택 보조표에서는 모든 설정에서 같은 1문항을 제외했다.
- **Q05 — 거짓 실패:** 400/40·800/80·1200/120의 주 지표에는 천장 표준모델에 4000~5000K 조명을 적용한다는 원문이 있다. 모델은 이 문장을 인용하면서도 대상 명칭은 없다고 오판했다. 실제 문장으로 대상·수치의 연결을 확인해 정정했다. Top 10도 해당 원문이 검색된 설정만 정정했다.
- **Q17·Q18·Q20 — 표 인용 오류:** 정답 행은 검색됐지만 모델이 파이프 구분자·`<br>`를 없애거나 ‘MRE는’처럼 조사를 덧붙여 인용했다. 형식 오류와 실제 검색 실패를 구분했다.
- **Q23 — 대상 문맥 상실:** BASE·400/40·800/80에는 인증·약 7개월의 안내는 있지만 ‘해당 모델’이 반원형이라는 연결 문맥이 없다. 일반 라인업 열거와 다른 쪽의 안내만으로 연결하지 않고 실패로 판정했다. 1200/120·1600/160은 p.10의 모델명·반원형 표기와 인증 안내를 함께 검색했다.
- **Q24 — 거짓 통과:** 1600/160은 슬림타입 천장의 에어컨 미적용 문장을 검색하지 못했다. 그런데 모델은 일반 상부 에어컨 설치나 소방구조용 안내를 인용하고, 이유에는 근거가 없다고 쓰면서도 `supported`를 반환했다. 실패로 정정했다.
- **추출 진단 4문항:** OCR 오탈자·표 셀 누락은 남아 있다. 모델이 오탈자를 정답으로 보정하려는 문제도 있어 자동 진단 통과 수를 추출 품질 개선으로 읽지 않는다.

## 결론의 민감도와 BASE 대비 차이

**Q23에서 출처 쪽수만으로 대상 모델의 연결을 허용하면 400/40은 23/29, 1600/160은 22/29로 순위가 바뀐다.**
이번에는 기존 평가 원칙인 ‘올바른 대상까지 검색 근거로 확인’을 엄격하게 적용했다.
차이가 작으므로 Q04의 형태 조건을 보완하고 Q23 기준을 독립 검토자와 맞춘 뒤 새 질문으로 확인해야 한다.

1,600/160과 BASE의 주 지표에서 후보만 성공한 문항은 Q05(색온도)·Q22(외부 승강로 공간 활용)·Q23(반원형 모델 인증)이다.
BASE만 성공한 것은 Q26(소방구조용 깊이 조건)으로, **3승 1패·순증 2문항**이다.
Top 10은 후보만 성공한 것이 Q05·Q22·Q23·Q29·Q31, BASE만 성공한 것이 Q26이다.
같은 페이지·표를 공유하는 문항이 있으므로 29개의 독립 시행으로 통계적 결론을 내리지 않는다.

## 실행·복구·사용량

- 원본 4개의 고정 추출 블록을 공유하고 설정 외 조건을 고정했다. 앱 소스·DB·색인·기본값은 변경하지 않았다.
- 평가 모델은 `gpt-4o-mini-2024-07-18`, 임베딩은 `text-embedding-3-small`이다.
- 최종 680개 결과: 새 정상 평가 응답 641건, 평가 캐시 재사용 39건.
- 임베딩 API 106회, 입력 1,212,958토큰(질문 포함).
- 정상 평가 응답 입력 2,533,566토큰·출력 127,607토큰. **중단 당시 응답의 사용량은 보존되지 않아 이 합계에 포함하지 못했다.** 금액은 산정하지 않았다.
- 554건 완료 후 응답 검증 `ValueError`로 한 번 중단됐다. 초기 코드는 세부 검증 이유를 저장하지 않아 구체적 원인은 확정할 수 없다. 남은 126개 조합을 재개해 완료했고 완료된 판정·색인은 재실행하지 않았다.
- 재개할 때 입력·모델·프롬프트를 확인하고 두 실행 코드의 해시를 `attempts`에 기록했다. 종료 시 원본·기존 앱 색인 스냅샷은 시작 시점과 일치했다.
- 실험·재개·기존 청커·검색·권한 관련 테스트 **82개 통과**. 인용 검증과 모델의 의미 판정이 완벽하다는 뜻은 아니다.

로컬 산출물은 `.venv/chunk_experiment/3839e06c05968f64af25/`에 저장하며 Git에서 제외한다.

- `results_size_d976c9d5f7b3.json`: 원래 검색 결과·자동 판정. 상태도 `complete_pending_manual_review`로 보존한다.
