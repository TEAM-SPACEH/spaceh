# 청킹 실험 자료

## 현재 앱 설정과 실험 기록의 구분

I-02 기본값을 800자·오버랩 80자로 조정하는 #136 변경에 포함한 자료다.
기존 결과 문서의 “앱 기본값 800/150 유지”는 **실험 실행 당시의 상태**를 기록한 것이다.
실험 코드의 BASE도 당시 비교 기준인 **800/150을 명시적으로 유지**한다. 현재 앱 기본값을 따라 바꾸지 않는다.

설정 변경은 새 업로드·재색인부터 적용된다. 실행 중인 앱은 재시작하고 기존 문서는 관리자 화면에서 재색인해야 한다.
이 변경은 DB·기존 색인을 자동으로 교체하지 않는다. 재색인은 외부 임베딩 API 사용량과 비용을 발생시킬 수 있다.
되돌릴 경우 이전 설정을 적용하고 영향받은 문서를 다시 재색인해야 한다. 코드만 되돌려도 이미 저장한 청크는 복원되지 않는다.

## 공유·재현 범위

계획·질문 JSON·최종 결과·실험 스크립트·테스트는 저장소에서 공유한다.
원본 문서·`.env`·실험 색인·캐시·본문이 포함된 원시 결과 JSON은 Git에 올리지 않는다. 원본은 팀 드라이브로 공유한다.
질문 JSON의 문서 ID는 실험 PC의 DB 등록 ID이므로, 다른 PC에서 재현할 때는 같은 원본 SHA-256을 확인하고 해당 PC의 등록 ID로 문서 목록과 질문의 연결을 맞춰야 한다.
같은 원본이라도 추출·OCR·검색 후보 변동으로 과거 점수가 그대로 재현된다고 보장하지 않는다.

이 결과는 **검색 근거의 필수 사실 충족 여부**에 대한 개발 실험이다. 답변·보고서 생성 정확도나 일반적인 최적값을 검증한 결과가 아니다.
