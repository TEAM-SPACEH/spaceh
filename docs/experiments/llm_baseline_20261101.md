## 근거를 대조해 확인한 점

- **Q02:** 하이브리드는 사업보고서 `#0105`에서 IT서비스 범위를 열거한 문장을 찾았지만, 벡터는 필요한 업무 범위를 찾지 못했다.
- **Q05¹ — 모델의 거짓 실패:** 하이브리드는 카탈로그 p.15 `#0027`을 검색했다. 본문에 “당사 천장 표준모델은 4000~5000K 조명을 적용합니다.”가 그대로 있다. 모델은 이 문장을 색온도의 근거로 인용하면서도 ‘천장 표준모델’은 근거가 없다고 판정했다. 수동 검토에서는 **통과로 정정**한다. 벡터 Top 10에는 p.15가 없다.
- **Q12² — 잘못된 인용과 의미 판단:** 하이브리드 판정은 다른 청크 `#0020`에 있는 문장을 `#0002`의 인용으로 제시했다. 또한 ‘레바논의 헤즈볼라 무장해제 요구’를 ‘가자의 국제안정화군 배치’ 근거로 인정했다. 로컬 인용 검증이 이를 통과시키지 않았다. 검색된 해당 DOCX 청크 2개에는 요구된 정치 조건과 지급 조건 전체가 없으므로 수동 검토에서는 **실패로 정정**한다.
- **Q03·Q08:** 모델이 OCR 오탈자를 올바른 조직명·처리 단계로 해석하거나, 원문과 다른 표기로 인용했다. 인용 최소 길이 검사 때문에 검토 대상으로 남았다. 이는 의미 검증이 OCR 오류를 정확하게 잡았다는 뜻은 아니다. 짧은 정상 근거도 이 검사에 걸릴 수 있으므로 이 항목들을 검색 실패로 자동 집계하지 않는다.

Q05·Q12의 수동 정정을 반영하면 청킹 비교용 결과는 **벡터 5/8, 하이브리드 7/8**이다.
원본 자동 결과는 수정하지 않았다. 전체 문항을 독립적으로 재채점한 결과는 아니며, 나머지 자동 판정에도 오류가 있을 수 있다.

## 실행 정보와 해석 범위

- 모델: `gpt-4o-mini-2024-07-18`, 임베딩: `text-embedding-3-small`.
- 기존 4개 문서·1,736개 청크, 동일 질문 임베딩, 검색별 Top 10. 실행 중 원본·색인 스냅샷이 유지됐다.
- 실제 평가 요청 24건: 입력 97,412토큰, 출력 5,029토큰. 질문 임베딩 651토큰. 금액은 별도 산정하지 않았다.
- 원본 결과: 로컬 `.venv/retrieval_eval/results.json`. 질문·청크·인용·검증 결과·사용량·요청 ID를 포함하며 Git에 올리지 않는다.
- 평가기 단위 테스트 18개 통과. 앱 소스·DB·색인·기본 검색 설정은 변경하지 않았다.

이 결과는 **현재 색인의 기준선 점검**이다. 새 실험의 네 청크 설정(A~D)을 비교한 결과가 아니다.
개발 점검용 12문항이며 일부 과거 문항을 재사용했다. 독립 검증 세트가 아니므로 하이브리드의 일반적인 우위나 최적 청크 크기를 확정하지 않는다.
